# Aufbau-Editor

Ein Editor im Browser, der Masken für SoftEngine baut. Eine Maske wird als HTML-Datei plus SEvariablen-Blatt exportiert und ersetzt in SoftEngine die eingebaute Oberfläche einer Karteikarte.

## Stand dieses Zweigs

Dieser Zweig ist ein **angefangener Neubau** und läuft noch nicht: es gibt das Modell (`src/model`) und den SoftEngine-Anschluss (`src/softengine`), aber weder Editor noch Bausteine noch Export. `npm run dev` scheitert.

Alles Weitere steht in [`UEBERGABE.md`](UEBERGABE.md): was gewollt ist, was entschieden wurde, was geschrieben ist und was fehlt.

Der lauffähige alte Editor liegt unverändert auf dem Zweig `main`.
